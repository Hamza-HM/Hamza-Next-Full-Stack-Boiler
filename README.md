# Hamza Next Full-Stack Boilerplate

Production-oriented **Next.js** starter for full-stack TypeScript applications — structured for real projects, not demos.

## Stack

- **Next.js** (App Router)
- **TypeScript**
- **React**
- Modern tooling and project layout for scalable apps

## Features

- Full-stack Next.js foundation
- TypeScript-first setup
- Clean structure for APIs, UI, and shared logic
- Ready to extend with auth, database, and deployment targets (Vercel, Docker, etc.)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm run start` | Run production server |
| `npm run lint` | Lint the codebase |
